## 2. ติดตั้งใหม่ตั้งแต่ต้น (ถ้าต้องทำซ้ำ)

ปกติไม่ต้องทำ (ติดตั้งเสร็จแล้ว) ใช้เมื่ออยากสร้างใหม่ในบัญชีอื่น

1. **สร้าง repository**: เข้า github.com → ปุ่ม **+** มุมขวาบน → **New repository**
   - Repository name: ตั้งชื่อ (เช่น `Finance_web`)
   - เลือก **Public** (GitHub Pages ฟรีต้องเป็น Public — โค้ดและข่าวคนอื่นเห็นได้ แต่คีย์ไม่หลุดเพราะอยู่ใน Secrets)
   - เปิด **Add README** → กด **Create repository**
2. **อัปโหลดไฟล์** ทีละโฟลเดอร์ (ต้องทำทีละโฟลเดอร์เพื่อให้ไฟล์อยู่ในโฟลเดอร์ที่ถูก):
   - ไฟล์นอกสุด: เปิด `https://github.com/<ชื่อบัญชี>/<ชื่อrepo>/upload/main` → ลากไฟล์ใส่ → **รอจนรายการไฟล์ขึ้นครบ** → กด **Commit changes**
   - โฟลเดอร์ย่อย: เปลี่ยนท้ายลิงก์เป็น `/upload/main/scripts`, `/upload/main/icons`, `/upload/main/.github/workflows` แล้วทำแบบเดียวกัน
   - ⚠️ ถ้ากด Commit ก่อนอัปโหลดเสร็จ ไฟล์จะไม่เข้า — ตรวจที่หน้า repo ว่ามีโฟลเดอร์ครบ
3. **ใส่ API key**: Settings → Secrets and variables → Actions → **New repository secret**
   - Name: `ANTHROPIC_API_KEY` / Secret: วางคีย์ → **Add secret**
4. **เปิดหน้าเว็บ**: Settings → **Pages** → Source: *Deploy from a branch* → Branch: **main** / **(root)** → **Save**
5. **รันครั้งแรก**: แท็บ **Actions** → **Daily news** → **Run workflow** → **Run workflow** (ปุ่มเขียว)
   รอ 2–3 นาทีให้ขึ้นเครื่องหมาย ✅ แล้วเปิดเว็บ `https://<ชื่อบัญชี>.github.io/<ชื่อrepo>/`

## 4. วิธีใช้แอป

- **เมนูล่าง**: 📰 ข่าว / 📈 ประวัติ / 🗓️ สรุปรายสัปดาห์
- **หน้าข่าว**
  - ปุ่มหมวดด้านบน 6 หมวด: หุ้นที่ติดตาม, ดอกเบี้ย Fed, ดีล, สินค้าใหม่, ภาพรวมตลาด, BTC & ทองคำ (ตัวเลข = จำนวนข่าว)
  - **ทุกข่าว / เฉพาะกระทบพื้นฐาน** — แนะนำให้ใช้ "เฉพาะกระทบพื้นฐาน" เป็นหลัก
  - แถวชื่อหุ้น (ในหมวดหุ้นที่ติดตาม): แตะเพื่อดูเฉพาะหุ้นตัวนั้น
  - ในการ์ดข่าว: ➕ ดี / ➖ ร้าย / ⚪ ยังไม่ชัด, ระดับความสำคัญ, เรื่องที่กระทบ และ 💡 เหตุผลจาก AI
  - ข่าว "เสียงรบกวน" แสดงจางลง / 🔒 = สำนักข่าวที่อาจต้องสมัครสมาชิกจึงอ่านเต็มได้
  - แตะชื่อหุ้น (ป้ายสีฟ้า) = เปิดกราฟบน TradingView / แตะหัวข่าว = เปิดข่าวต้นฉบับ
  - "อ่านจาก:" = สำนักอื่นที่ลงข่าวเดียวกัน (เผื่อสำนักแรกต้องเสียเงินอ่าน)
- **หน้าประวัติ**: ตารางสรุปทุกหุ้น (➕ ➖ ⚪ และจำนวนข่าวสำคัญสูง) → แตะแถวเพื่อดูไทม์ไลน์ 12 เดือน
  ติ๊ก "เฉพาะข่าวสำคัญสูง" เพื่อดูแต่ข่าวใหญ่ / มี MACRO = ข่าวเศรษฐกิจ/Fed
- **หน้าสรุปรายสัปดาห์**: ฉบับล่าสุด และเลือกดูย้อนหลังได้จากช่อง "เลือกสัปดาห์"
- **ช่องค้นหา** (ด้านบน): ค้นทุกหมวด เช่น พิมพ์ `nvidia` หรือ `Reuters` / ในหน้าประวัติจะค้นในประวัติ 12 เดือน
- **ปุ่ม ◐** มุมขวาบน: สลับ ตามระบบ → สว่าง → มืด
- **แถบเตือน** ที่อาจเห็นด้านบน:
  - 🤖 "AI ไม่ได้ติดป้ายข่าวรอบนี้" → ดูข้อ 11
  - ⏰ "ข้อมูลไม่ได้อัปเดตมา … ชั่วโมง" → ดูข้อ 11
  - 🗂️ "ข้อมูลเดือน … จะถูกลบในอีก … วัน" → ดูข้อ 10

## 5. แก้ไขไฟล์บนหน้าเว็บ GitHub (พื้นฐาน)

1. เข้า https://github.com/hcivapy/Finance_web แล้วคลิกชื่อไฟล์ที่จะแก้ (เช่น `watchlist.json`)
2. กดรูป **ดินสอ ✏️** (Edit this file) มุมขวาบนของไฟล์
3. แก้ข้อความ
4. กด **Commit changes…** (ปุ่มเขียว) → กด **Commit changes** อีกครั้ง
5. การแก้จะมีผลในรอบดึงข่าวถัดไป (07:00 น.) หรือกดรันเองได้ (ข้อ 11 → "อยากให้ดึงข่าวใหม่ตอนนี้")

**ข้อควรระวังไฟล์ .json** (รูปแบบข้อมูลที่เครื่องอ่าน เข้มงวดมาก)
- ข้อความต้องอยู่ใน `"..."` เสมอ
- ระหว่างรายการต้องมี `,` คั่น แต่ **รายการสุดท้ายห้ามมี `,`** ต่อท้าย
- วงเล็บ `{ }` และ `[ ]` ต้องเปิด-ปิดครบคู่
- ก่อนกด Commit: คัดลอกข้อความทั้งไฟล์ไปวางที่ **https://jsonlint.com** แล้วกด Validate — ถ้าขึ้น "Valid JSON" แปลว่าใช้ได้
- ถ้าแก้ผิดจนระบบพัง: เปิดไฟล์ → ปุ่ม **History** → เลือกเวอร์ชันก่อนหน้า → ดูข้อความเดิมแล้วคัดลอกกลับมาแก้

## 6. เพิ่ม/ลบ หุ้นใน watchlist

ไฟล์: **`watchlist.json`** → ส่วน `"stocks": [ ... ]`

### เพิ่มหุ้น
คัดลอกบล็อกของหุ้นที่มีอยู่ (ตั้งแต่ `{` ถึง `}`) แล้ววางต่อท้าย (อย่าลืม `,` คั่นระหว่างบล็อก) จากนั้นแก้ค่า เช่น เพิ่ม Apple:

```json
{ "id": "AAPL", "name": "Apple", "tickers": ["AAPL"], "country": "US", "tradingview": "NASDAQ-AAPL",
  "keywords": ["Apple", "iPhone", "Tim Cook"], "exact_words": ["AAPL"],
  "exclude": ["apple juice", "Apple Daily"],
  "search": "Apple OR iPhone" }
```

| ช่อง | ความหมาย |
|---|---|
| `id` | ชื่อย่อที่แสดงในแอป (ห้ามซ้ำกับตัวอื่น) |
| `name` | ชื่อบริษัท |
| `tradingview` | ตลาด-ticker สำหรับลิงก์กราฟ ดูได้จากลิงก์บน TradingView เช่น `tradingview.com/symbols/NASDAQ-AAPL/` → `NASDAQ-AAPL` |
| `keywords` | ชื่อที่เจอแล้วนับเป็นข่าวบริษัทนี้ทันที (ไม่สนตัวพิมพ์เล็ก/ใหญ่) ใส่ `*` ท้ายคำ = คำที่ขึ้นต้นแบบนี้ |
| `exact_words` | ชื่อที่ตัวพิมพ์ต้องตรงเป๊ะ เหมาะกับ ticker |
| `weak_words` + `context` | สำหรับ ticker ที่เป็นคำทั่วไป (เช่น AMD, MU) — นับเป็นข่าวบริษัทเฉพาะเมื่อมีคำใน `context` อยู่ด้วย |
| `exclude` | ถ้าข่าวมีคำพวกนี้ ไม่นับเป็นข่าวบริษัทนี้ |
| `search` | คำค้นใน Google News: **ชื่อคั่นด้วย OR เท่านั้น** ใส่ `"..."` ครอบชื่อหลายคำ **ห้ามใส่วงเล็บหรือคำอื่นเพิ่ม** (ผลค้นจะหายหมด) |
| `search_all_sources` | `true` = รับข่าวจากทุกสำนัก (ใช้กับหุ้นที่ข่าวน้อย เช่นหุ้นญี่ปุ่น) ถ้าไม่ใส่ = รับเฉพาะสำนักที่น่าเชื่อถือ |

### ลบหุ้น
ลบทั้งบล็อก `{ ... }` ของหุ้นนั้น และตรวจว่าไม่มี `,` เกินหรือขาด → ตรวจที่ jsonlint.com
ประวัติเก่าของหุ้นที่ลบยังอยู่ในไฟล์ `history/` จนครบ 12 เดือน

> ค่า AI จะเพิ่มขึ้นตามจำนวนข่าว — หุ้นใหญ่ 1 ตัวเพิ่มประมาณ $0.05–0.15/เดือน

## 7. เพิ่ม/ลบ/ปิด แหล่งข่าว

ไฟล์: **`sources.json`**

- **ปิดชั่วคราว**: เปลี่ยน `"enabled": true` เป็น `"enabled": false`
- **ลบ**: ลบทั้งบรรทัด `{ ... }` ของแหล่งนั้น (ระวัง `,`)
- **เพิ่มแหล่ง RSS**: คัดลอกบรรทัดของแหล่งที่คล้ายกันใน `"feeds"` แล้วแก้
  ```json
  { "source": "ชื่อสำนักข่าว", "name": "ชื่อฟีด", "url": "ลิงก์ RSS", "categories": ["watchlist", "deals"], "paywall": false, "enabled": true },
  ```
  - `categories` = หมวดที่ข่าวจากแหล่งนี้มีสิทธิ์เข้า: `watchlist` (หุ้น), `fed`, `deals` (ดีล), `products` (สินค้าใหม่), `market` (ภาพรวมตลาด), `crypto_gold`
  - `paywall: true` = ติดป้าย 🔒
  - วิธีหาลิงก์ RSS: ค้นใน Google ว่า "ชื่อสำนักข่าว RSS feed" — ลิงก์มักลงท้ายด้วย `.xml`, `/rss` หรือ `/feed`
- **ค้นข่าวจากเว็บที่ไม่มี RSS** (ส่วน `"google_news" → "topics"`): ใช้ `site:ชื่อเว็บ` **เว็บเดียวต่อหนึ่งคำค้น** เช่น
  ```json
  { "name": "Reuters (ทองคำ)", "query": "site:reuters.com (gold OR bullion) when:2d", "categories": ["crypto_gold"], "paywall": false, "enabled": true }
  ```
- `trusted_sources` = รายชื่อสำนักที่ยอมรับเมื่อค้นข่าวหุ้นใน Google News / `paywall_sources` = สำนักที่ติดป้าย 🔒
- หลังแก้ ให้ดูผลในรอบถัดไป: แท็บ Actions → รอบล่าสุด → ขั้น "Fetch and label news" จะบอกว่าแหล่งไหนดึงไม่ได้ (`skipped`)

## 9. วงเงิน เครดิต และ API key

### ดูค่าใช้จ่ายจริง
- ในแอป GitHub: เปิดไฟล์ `data/ai_usage.json` → `month_to_date_usd` = ค่า AI เดือนนี้ (ดอลลาร์)
- หรือที่ Claude Console: https://platform.claude.com → **Usage** / **Cost**

### ตั้งวงเงินสูงสุด (Spend limit)
1. เข้า https://platform.claude.com → เมนู **Settings** → **Limits**
2. ที่ **Spend limits** กด **Change limit** → ใส่จำนวน (แนะนำ **$5/เดือน**) → **Save**
3. ถ้าถึงวงเงิน AI จะหยุดจนต้นเดือนถัดไป แอปยังแสดงข่าวได้ แค่ไม่มีป้าย

### เติมเครดิต
1. platform.claude.com → **Settings** → **Billing** → **Buy credits**
2. แนะนำครั้งละ ~$10 และ **ปิด Auto-reload** (กันการตัดเงินอัตโนมัติ)
3. เครดิตหมดอายุ 1 ปีหลังซื้อ และขอคืนไม่ได้

### เปลี่ยน API key (เมื่อคีย์หมดอายุ ~ก.ย. 2027 หรือสงสัยว่าคีย์หลุด)
Anthropic จะส่งอีเมลเตือน 7 วันก่อนคีย์หมดอายุ
1. platform.claude.com → **API keys** → **Create key** → ตั้งวันหมดอายุ 1 ปี → คัดลอกคีย์ (จะเห็นแค่ครั้งเดียว)
2. GitHub: repo → **Settings** → **Secrets and variables** → **Actions**
3. ที่ `ANTHROPIC_API_KEY` กดรูป **ดินสอ** (Update) → วางคีย์ใหม่ → **Update secret** (ชื่อเดิม ไม่ต้องเปลี่ยน)
4. กลับไป Claude Console ลบคีย์เก่า (ถ้ายังไม่หมดอายุ)
5. ทดสอบ: แท็บ **Actions** → **Daily news** → **Run workflow**

> ห้ามวางคีย์ในไฟล์ใดๆ ใน repo หรือในแชท — เก็บใน GitHub Secrets เท่านั้น

## 11. แก้ปัญหาที่พบบ่อย

### อยากให้ดึงข่าวใหม่ตอนนี้ (ไม่รอ 07:00 น.)
repo → แท็บ **Actions** → เมนูซ้าย **Daily news** → ปุ่ม **Run workflow** → **Run workflow** (เขียว) → รอ 2–3 นาที
(สรุปรายสัปดาห์: เลือก **Weekly summary** แทน)

### Actions ไม่รัน / ข่าวไม่อัปเดต (แถบ ⏰ ในแอป)
1. แท็บ **Actions** → ดูรอบล่าสุดของ **Daily news**
   - ✅ เขียว = รันสำเร็จ → รอ 1–2 นาทีให้หน้าเว็บอัปเดต แล้วปิด-เปิดแอปใหม่
   - ❌ แดง = ล้มเหลว → คลิกเข้าไป → คลิกขั้นที่มี ❌ เพื่อดูข้อความ
   - ไม่มีรอบใหม่เลย → ดูข้อ 2–3
2. GitHub อาจปิดการตั้งเวลาอัตโนมัติถ้า repo ไม่มีความเคลื่อนไหว 60 วัน (ปกติไม่เกิด เพราะระบบบันทึกข่าวทุกวัน)
   ถ้าเจอข้อความสีเหลือง "This scheduled workflow is disabled" → กด **Enable workflow**
3. รอบตั้งเวลาของ GitHub **อาจช้าได้ 15 นาที–1 ชั่วโมง** ในช่วงที่คนใช้เยอะ เป็นเรื่องปกติ
4. ถ้าแดงที่ขั้น "Save results": Settings → Actions → General → Workflow permissions → เลือก **Read and write permissions** → Save

### ข่าวไม่ขึ้น / แอปขึ้น "โหลดข่าวไม่ได้"
- ยังไม่เคยรันครั้งแรก → รัน Daily news ตามด้านบน
- Settings → **Pages** ต้องขึ้นว่า "Your site is live at …" (ถ้าไม่ใช่ ให้ตั้ง main / (root) → Save)
- เพิ่งแก้ไฟล์ .json แล้วพัง → ดู Actions รอบล่าสุด ถ้าแดงและมีคำว่า `JSONDecodeError` → แก้ไฟล์ให้ถูก (ข้อ 5)
- หมวดไหนไม่มีข่าวบ้างในบางวันเป็นเรื่องปกติ (โดยเฉพาะเสาร์-อาทิตย์)

### ป้าย AI หาย (แถบ 🤖 "AI ไม่ได้ติดป้ายข่าวรอบนี้")
แถบจะบอกสาเหตุ — ข่าวยังอ่านได้ และระบบจะลองติดป้ายใหม่รอบหน้า (ข่าวอายุไม่เกิน 48 ชม.)
| ข้อความ | วิธีแก้ |
|---|---|
| ไม่พบ API key | ใส่ `ANTHROPIC_API_KEY` ใน Secrets (ข้อ 9) — ชื่อต้องสะกดตรงเป๊ะ |
| API key ใช้ไม่ได้ | คีย์หมดอายุ/ถูกลบ → สร้างคีย์ใหม่แล้วแทนค่า (ข้อ 9) |
| เครดิตหมด | เติมเครดิต (ข้อ 9) |
| ถึงวงเงินสูงสุด | รอต้นเดือนถัดไป หรือเพิ่ม spend limit |
| ระบบ AI ขัดข้องชั่วคราว / เชื่อมต่อไม่ได้ | ไม่ต้องทำอะไร รอรอบหน้า |
| AI ตอบกลับผิดรูปแบบ | ไม่ต้องทำอะไร รอรอบหน้า ถ้าเกิดติดกันหลายวันให้แจ้ง Claude Code |

### สรุปรายสัปดาห์ไม่มา
- หน้าสรุปจะบอก "สัปดาห์ล่าสุดไม่มีสรุป" พร้อมสาเหตุ — ถ้าเพราะไม่มีข่าวกระทบพื้นฐานทั้งสัปดาห์ถือว่าปกติ
- สาเหตุเรื่องคีย์/เครดิต แก้เหมือนป้าย AI หาย แล้วกด Run workflow ของ **Weekly summary**

### ข่าวหุ้นตัวไหนไม่ค่อยมา หรือมีข่าวไม่เกี่ยวปน
- ข่าวน้อย: เพิ่มชื่อ/แบรนด์ใน `keywords` และ `search` หรือใส่ `"search_all_sources": true` (ข้อ 6)
- ข่าวปน: เพิ่มคำใน `exclude` ของหุ้นนั้น

### แอปบนมือถือไม่อัปเดตหน้าตาหลังแก้ไฟล์
ปิดแอปให้สนิท (ปัดทิ้งจากรายการแอปที่เปิดอยู่) แล้วเปิดใหม่ 1–2 ครั้ง
